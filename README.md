# Simple Python Task Manager (CLI)

A lightweight Command Line Interface (CLI) application to manage daily tasks. This project demonstrates Python fundamentals, file I/O using JSON, and Object-Oriented Programming (OOP).

## Features
- **Add Tasks**: Quickly save new items to your list.
- **Persistent Storage**: Tasks are saved in a `tasks.json` file so they remain even after closing the program.
- **Track Progress**: Mark tasks as complete with a simple ID reference.
